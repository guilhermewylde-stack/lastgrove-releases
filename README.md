# Last Grove: releases

Instalador e atualizações do **Last Grove** para o playtest com amigos. Este repositório guarda só os pacotes; o
código fica em outro lugar.

**Baixar:** [LastGrove-win-Setup.exe](https://github.com/guilhermewylde-stack/lastgrove-releases/releases/latest/download/LastGrove-win-Setup.exe) (Windows 10/11, 64 bits)

O instalador não tem assinatura digital: quando o Windows mostrar "O Windows protegeu o computador", clique em
**Mais informações** e depois em **Executar assim mesmo**. Depois de instalado, o jogo se atualiza sozinho ao abrir.
